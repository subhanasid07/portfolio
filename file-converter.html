Good to know
  • .docx converts with formatting preserved (text, headings, tables, basic styling).
  • .xlsx / .xls / .csv converts each sheet into a formatted table, one per page.
  • .pptx extracts slide text only (no images or exact layout) — browsers can't render true PPTX slides.
  • Legacy binary .doc and .ppt files aren't supported — open them in Word/PowerPoint and save as .docx/.pptx first.
